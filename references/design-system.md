# 视觉基准

黑底、白线、蓝绿与留白是可复用的视觉语言。字体和基础布局在 `assets/template/`。参考图 `approved-carousel.png` 只用于观察线条、对比度与节奏，其中的品牌、Together、人物、圆桌与篇章结构不应移植到新文章。

## 颜色与层次

| 用途 | 色值 |
| --- | --- |
| 画板 | `#000000` |
| 标题、引语 | `#f5f7f5` |
| 正文 | `#d4d9d6` |
| 次级文字 | `#a1aaa5` |
| 青绿重点 | `#00f0d5` |
| 钴蓝实体 | `#1550ff` |
| 细线 | `#3e4742` |
| 浏览器预览背景 | `#121514` |

钴蓝落在与文章有关的实体上，不固定是椅子或衣服；青绿标记少量重点、序号和主题词。正文不大段着色。保持平面、安静，不加光晕、阴影、灰色 3D 或背景纹理。用户指定的颜色优先。

## 字体与尺寸

内置 MiSans Regular / Semibold，本地 WOFF2。以下是 1080 画板的起点，信息多时优先拆页。

| 角色 | 字号与行高 |
| --- | --- |
| 常规内页标题 | 64px / 1.22，600 |
| 大标题变体 | 76px / 1.22，600 |
| 正文 | 31px / 1.6，400 |
| 主要引语 | 33–40px / 1.5，600 |
| 结论 | 34px / 1.5，600 |
| 说明 | 24–28px |
| 页码 / 页脚 | 22px / 20px |
| 封尾展示字 | 约 130–180px，随词长重排 |

标题字距约 −.025em，正文保持自然字距。英文主题短词的字形必须由生图模型创作；正文仍使用可编辑的本地字体，不把装饰笔势强加给中文正文。

## 画板与网格

- 1080×1440，横向内边距 80px；页头顶部 64px。
- 正文从 174px 到距底部 132px，页脚距底部 48px。
- 模块间距约 24px，密集页 20px；结论上方细线、内边距 30px、`margin-top:auto`。
- 图文双栏可从 1.13 : 0.87、间距 28px 起步，依据文字与图像调整。
- `.content > * { flex-shrink:0 }` 保留真实高度；图像使用原始比例。
- 默认页头只有右侧页码，不添加填补空间的假品牌或无关英文标签。

## 主题字形与镂空

先根据文章选英文短词，用生图模型创作字形，再决定位置，详见 [wordmarks.md](wordmarks.md)。实心与镂空必须来自同一份生成图片。可通过 SVG 的 alpha/亮度蒙版与形态滤镜派生轮廓，使内部透明；SVG 负责呈现效果，不负责排字。不要用现成字体、黑色字配粗外框或两张不同字形的图代替。

`.theme-backdrop` 是可选正文下层：默认宽 1400px、left −160px、top 560px、旋转 −8°、透明度 .20，可逐篇、逐页用 CSS 变量调整。短词形状不同，不应固定套用位置与尺寸。画板 `isolation:isolate`，背景 z0、正文 z1，`pointer-events:none`、`aria-hidden:true`；允许字形出血，正文不能出血。

封面或结尾可用同源实心主题词。它不是固定 Logo，不必每页出现。结尾另设计视觉落点，保留与正文一致的页边距、配色与主题，不机械套用空椅、下一场圆桌或评论区邀请。

## 品牌与素材

默认没有品牌。用户指定后才配置 `data-logo-one` / `data-logo-two` 与可选名称，支持零、一个或两个 Logo；比例使用资产本身，不拉伸。

新项目只复制字体。旧版 `arc-black-xhs` 与其素材独立保留；本技能不附旧品牌、字标或插画。新生成插画、主题字形、用户提供的照片都保存在本篇项目的 `assets/`。

## 预览

画板整体缩放，移动端不重新折行。桌面两列、窄屏一列；预览控件和下载链接不进入 PNG。`viewer.js` 自动生成页码、进度、图注和下载链接；无主题背景时隐藏其切换按钮。
