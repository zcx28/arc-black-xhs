# 视觉基准

这些规则来自已确认的 Together 圆桌图文。`assets/template/styles.css` 是可直接复用的实现；`approved-carousel.png` 是视觉参考，原来的九页内容只是一个案例。

## 颜色和层次

| 用途 | 色值 |
| --- | --- |
| 发布画板 | `#000000` |
| 标题、引语 | `#f5f7f5` |
| 正文 | `#d4d9d6` |
| 次级文字 | `#a1aaa5` |
| 青绿重点 | `#00f0d5` |
| 钴蓝插画实体 | `#1550ff` |
| 细分隔线 | `#3e4742` |
| 浏览器预览背景 | `#121514` |

钴蓝主要承载座椅、衣服等实体，青绿标记重点、序号和字标。正文不要大段着色。留白、字重和细线承担层次，少用容器边框、卡片、圆角色块和多余说明标签。保持平面、安静的画面，不增加光晕、阴影、灰色 3D 建模或背景纹理。

## 字体与尺寸

内置 MiSans Regular / Semibold，均为本地 WOFF2。画板原尺寸的字号如下；浏览器控件不采用这个尺度。

| 角色 | 字号与行高 |
| --- | --- |
| 常规内页标题 | 64px / 1.22，600 |
| 大标题变体 | 76px / 1.22，600 |
| 长段正文 | 31px / 1.6，400 |
| 主要引语 | 38px / 1.5，600；依空间可在 33–40px 调整 |
| 结论 | 34px / 1.5，600 |
| 说明文字 | 24–28px |
| 页码 | 22px |
| 页脚 | 20px |
| 封尾英文展示字 | 133–182px，400，按词长排版 |

大字采用负字距（标题约 −.025em），正文保持自然字距。封尾长英文需要重新排版，不能把所有标题硬塞进 OPEN / QUESTIONS 的固定位置。

## 画板与网格

- 画板 1080×1440；横向内边距 80px。
- 页头顶部 64px；正文从 174px 到距底部 132px；页脚距底部 48px。
- 主要模块间距 24px，密集页可用 20px；结论区上方细线，内边距 30px，`margin-top:auto`。
- 图文相邻双栏约 1.13 : 0.87，间距 28px。文字区要足够宽，插画提供氛围，不必解释每一个名词。
- 人物名 / 引语双栏 115px / 其余宽度，间距 22px。
- `.content > * { flex-shrink:0 }` 保留真实内容高度；`.lead-art { width:100%; height:auto }` 保留图片比例。
- 不依赖压缩字号挤内容；优先删冗余、调整分段或拆页。

## 固定品牌资产

都在 `assets/template/assets/`，`asset-manifest.json` 记录用途和哈希。

- `tinuehub-white.png`、`rift-white.png`：已确认的白色品牌版本，保持原始比例。页头默认宽度分别 142px、158px。
- `together-cyan.png`、`together-white.png`：真透明 PNG，原始比例 1705:774，四周保留透明边距。
- `together-white.svg`：固定轮廓路径母版。
- `together-outline.svg`：同一组路径，`fill:none`、青绿描边，不是另找一个手写字体。

半透明背景字位于内页正文下层，默认宽 1440px，left −180px、top 560px，rotate(−8deg)，opacity .28。SVG 描边宽 3.4 单位。画板 `isolation:isolate`，背景 z0、正文 z1，`pointer-events:none`、`aria-hidden:true`。允许字形出血，文字不出血。默认位置和透明度是已确认起点；若干扰正文可微调，先看整页效果。模板预览有显示/隐藏开关，默认导出保留。

## 结尾的设计

与正文保持品牌、配色和页边距，另用放大的英文短句建立节奏。空蓝椅、圆桌、Together 实心字标可以形成一个视觉落点，留一句中文邀请和一个行动。

“NEXT ROUND.”、空椅与 “YOU” 适合开放讨论；项目分享或访谈可以选更贴切的短句或场景。避免最后一页只是把更多正文堆在末尾，也不要编造日期、地址、报名链接或下一期安排。

## 预览

固定画板整体缩放，不让移动端重新折行排版。桌面两列、窄屏一列；预览控件、下载链接和灰色外框不会进入发布 PNG。`viewer.js` 根据实际 `.page` 数量生成页码、进度、图注和下载链接。
